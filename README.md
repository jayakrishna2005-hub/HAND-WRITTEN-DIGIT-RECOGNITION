# Handwritten Digit Recognition

This project is a lightweight handwritten digit recognition web app built with HTML, CSS, and JavaScript. It includes a canvas area for drawing digits and a simple Python server to serve the frontend locally.

## Features

- Draw digits on a canvas
- Clear the canvas
- Simple web UI for digit recognition
- Local Python server for development

## Run locally

1. Open a terminal in this project folder.
2. Start the server:

```bash
python3 server.py
```

3. Open the browser at:

```text
http://localhost:8000
```

## Project structure

- `index.html` – main page layout
- `style.css` – styling for the UI
- `app.js` – browser logic for drawing and interaction
- `server.py` – local server to serve the app

## Notes

This is a front-end demo project and can be extended with a trained ML model or backend classifier.
